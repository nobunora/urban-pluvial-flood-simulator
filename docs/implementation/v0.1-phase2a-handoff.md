## Scope boundary

Phase 2A is limited to application-owned geographic provider integration:

```text
GSI elevation
PLATEAU vectors
OSM fallback
provider provenance/errors/network policy/cache compatibility
legacy script compatibility wrappers
```

Do not implement CSIS geocoding, JMA rainfall catalogs/APIs, SFINCS production flow, Adaptive, result rendering, or UI work in Phase 2A.

Phase 2 is intentionally split:

```text
2A geographic providers
2B geocoder + JMA catalog/APIs
```

Phase 3 may begin only after both 2A and 2B are validated.
