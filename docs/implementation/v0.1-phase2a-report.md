## Authoritative modules

Created under `floodsim/providers/`:

- `common.py` — typed provider errors, deterministic provenance, WGS84 AEQD
  helpers, and the shared network/retry policy.
- `gsi_elevation.py` — GSI tile cache, exact signed RGB decode, fallback
  mosaic, rectangular normalized elevation product, and source counts.
- `plateau.py` — PLATEAU catalog/CityGML acquisition, EPSG:6697 axis handling,
  footprint preference, and normalized buildings/roads.
- `osm.py` — independent Overpass building/highway fallback, rectangular
  clipping, and attribution.
- `vectors.py` — `auto`, `plateau`, and `osm` orchestration with narrowly typed
  PLATEAU-to-OSM fallback.

The former `scripts/download_*` modules now delegate to these providers. Their
legacy square callables and CLI argument forms remain available, and
`scripts/prepare_area.py` uses application-owned providers before the existing
hydraulic preprocessing step.

## Contract evidence

- Application providers accept `AnalysisArea`, including arbitrary rectangles.
  GSI normalization uses `nx = round(width_m / grid_m) + 1` and
  `ny = round(height_m / grid_m) + 1`; x/y are explicit local metres and the
  normalized array is south-to-north in y.
- GSI priority is unchanged: `DEM1A -> DEM5A -> DEM5B -> DEM5C -> DEM10B`.
  The exact signed 24-bit positive, negative, and `2^23` NoData rules are in
  the provider and covered by tests. Nearest-fill count and pre-fill missing
  fraction are provenance fields; excessive missing coverage raises
  `ProviderCoverageError`.
- PLATEAU requests `bldg,tran`, parses CityGML latitude/longitude/elevation
  axis order through EPSG:6697, prefers
  `lod0FootPrint -> lod0RoofEdge -> GroundSurface -> generic polygon`, and
  prefers road polygons while retaining line geometry when no polygon exists.
- OSM requests only `building` and `highway`, clips to the rectangular local
  extent, and reports `© OpenStreetMap contributors`, the copyright URL, and a
  completeness/geometry-quality warning.
- `auto` catches only `ProviderError` from PLATEAU. It records the failure
  category/message in OSM provenance; unexpected programming exceptions do not
  trigger fallback. If both providers fail, one typed error retains both
  diagnostics.
- Provenance contains provider id/name, requested WGS84 bounds, UTC acquisition
  time, attribution, terms URL, warnings, and JSON-serializable source details.
  It contains no machine-specific cache path.
- Cache identity is provider-specific: GSI layer/zoom/x/y, PLATEAU source URL
  hash, and OSM area identity. Cached bytes are decoded/parsed before use.
- Network policy is centralized: connect 10 s, read 60 s, three attempts,
  1 s/2 s backoff, HTTP 429/500/502/503/504 retry statuses, and user agent
  `urban-pluvial-flood-simulator/0.1`.
