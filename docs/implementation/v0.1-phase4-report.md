## Foundation implemented

- Preserved the Full 1 m road mask as normalized input to Adaptive hard-refinement decisions.
- Added the fixed `1, 2, 4, 8, 16, 32 m` hierarchy and canonical provisional RMSE/max-residual thresholds.
- Added least-squares plane-fit RMSE, maximum residual, curvature, local depression/ridge connectivity evidence, and deterministic D8 flow-accumulation concentration diagnostics for candidate blocks.
- Kept building and road source cells at exactly 1 m.
- Implemented the §12.2 `within 2 m` feature buffer in projected metric space using Euclidean distance between normalized 1 m source-cell footprints; buffer cells may be 1 m or 2 m but never coarser than 2 m.
- Added deterministic 2:1 edge-neighbour balancing.
- Added cell counts by level, total hydraulic cells, Full-1 m equivalent cells, reduction ratio, refinement-reason raster/summary, and grid-resolution layer.
- Threshold configuration identity is now derived deterministically from the actual RMSE/max-residual values rather than a static label.

## Quadtree CRS compatibility blocker

Pinned HydroMT-SFINCS rc3 `SfincsQuadtreeGrid.write()` converts the quadtree to a Dataset, preserves full `crs_wkt`, and then also writes authority metadata using `self.crs.to_epsg()`. The canonical local AEQD CRS has no EPSG authority, so the writer produces an invalid `epsg=None` / `epsg_code="EPSG:None"` metadata combination and the NetCDF write fails.

The source-level recommended seam is a repository-owned, quadtree-only adapter that preserves normal rc3 Dataset preparation and full WKT/CF/UGRID CRS metadata while omitting only invalid optional authority metadata for an authority-less CRS. A fake permanent EPSG is prohibited.

Web has intentionally not implemented that private-rc3 adapter yet because the preceding Codex audit did not independently complete the runtime reproduction/round-trip probe. The next validation pass must reproduce the failure with the pinned rc3 and verify that WKT-only metadata round-trips through the pinned reader before Web implements the adapter.
