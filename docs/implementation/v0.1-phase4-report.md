## Web repair: staged rc3 refinement

Production refinement no longer sends the multi-level classifier polygons to `refine_in_polygon()`.

The repaired path:

1. creates the actual pinned-rc3 32 m base quadtree;
2. visits existing rc3 levels monotonically from 32 to 1 m;
3. maps each parent cell through rc3 `n/m` indices to its Full-1 m source block;
4. refines a parent only when that block contains a validated target finer than the parent;
5. calls pinned rc3 `QuadtreeGrid.refine_cells()` only for the current existing level;
6. reruns rc3 neighbour, UV and UGRID finalization;
7. installs the resulting rc3-generated Dataset on the model component;
8. restores the canonical authority-less AEQD CRS and config `epsg=None` / correct `crsgeo`.

Classifier polygonization remains available for diagnostics only. The hydraulic safety invariant remains:

```text
actual source-overlapping face size <= every classifier target cell covered by that face
```

Extra rc3 transition/sibling refinement is allowed; coarser-than-target geometry is rejected.

## Face fields and padding

- Base dimensions are `ceil(width/32)` by `ceil(height/32)`.
- Outside-domain padding has zero source overlap, mask 0 and zero rain contribution.
- Actual `level/n/m` faces are mapped back to aligned Full-1 m source blocks.
- Building cells remain blocked and direct road cells retain Manning `0.020`.
- Roof-rain face weights are area-conservative and checked against the Full-1 m weighted source area.
