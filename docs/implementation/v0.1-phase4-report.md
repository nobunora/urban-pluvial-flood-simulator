## Confirmed upstream limitation

Pinned rc3 `SfincsQuadtreeGrid.write()` calls `self.crs.to_epsg()` and writes the result into optional `mesh2d_crs` EPSG metadata. For the canonical authority-less local AEQD, the result is `None`, causing NetCDF serialization failure. Codex independently reproduced the failure and independently proved that WKT-only authority metadata survives pinned xugrid/rc3 round trip. This is classified as an upstream rc3 authority-less-CRS writer limitation, not repository misuse or a specification conflict.
