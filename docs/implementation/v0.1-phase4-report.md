## First actual-quadtree failure at `1aeebc...`

Codex ran the committed actual-quadtree tests. Flat 64x64 passed, while hard building/road and odd 33x35 cases failed in pinned HydroMT-SFINCS 2.0.0rc3 `refine_in_polygon()` with deterministic intermediate-level indexing errors.

The previous production path supplied several classifier-derived polygons with different refinement depths. Pinned rc3 restarts every polygon at level zero; an earlier polygon can consume every cell at an intermediate level that a later polygon then assumes still exists. Codex made no source correction.

Web removed polygon-driven production refinement. Classifier polygonization remains diagnostic-only.

## Second actual-quadtree failure at `0e5cbef...`

The first staged repair moved production refinement to pinned rc3 `QuadtreeGrid.refine_cells()`. Codex then reproduced a second deterministic `IndexError` in hard building/road, odd 33x35, and asymmetric 65x34 tests.

`refine_cells()` invokes rc3 `find_lower_level_neighbors()` whenever the current level is greater than zero. If all cells at the immediately-coarser level have already been consumed globally, rc3 passes an empty coarser-level array into `binary_search()` and fails. In that state a coarser neighbor cannot physically exist, so the failure is an upstream hierarchy-state assumption rather than an ambiguous hydraulic rule.

Codex again made no source correction.

## Current Web repair: staged refinement with equivalent base rebalancing

Production still uses pinned rc3 `refine_cells()`; rc3 is not monkey-patched.

The repaired path now:

1. creates the actual pinned-rc3 32 m base quadtree;
2. processes physical parent sizes monotonically `32 -> 16 -> 8 -> 4 -> 2 -> 1 m`;
3. maps each actual parent through rc3 `n/m` indices to its Full-1 m classifier block;
4. selects a parent only when its source block contains a validated target finer than that parent;
5. before each stage/iteration, finds the first populated rc3 level;
6. if every globally coarser level has disappeared, promotes that first populated level to level zero with the equivalent transform:

```text
factor = 2 ** leading_level
dx, dy = dx / factor, dy / factor
nmax, mmax = nmax * factor, mmax * factor
level = level - leading_level
```

`n/m` indices are unchanged. Therefore physical cell extents and coordinates are unchanged; only the quadtree's base representation is rebased so pinned rc3 no longer searches a globally empty immediately-coarser level.

After staged refinement the implementation:

- rejects internal level gaps;
- re-runs rc3 ordering, first/last-level indexing, centre coordinates, neighbors, UV points and UGRID finalization;
- installs the rc3-generated Dataset on the model component;
- restores canonical authority-less AEQD and config `epsg=None` / projected `crsgeo=0`;
- derives physical face size from the Dataset's actual base `dx` after any rebase rather than assuming permanent 32 m level zero.

The hydraulic safety invariant remains:

```text
actual source-overlapping face size <= every classifier target cell covered by that face
```

Extra rc3 transition/sibling refinement is allowed; coarser-than-target geometry is rejected.
