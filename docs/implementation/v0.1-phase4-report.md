### 1. Classifier to rc3 refinement geometry

Pinned rc3 starts from a 32 m base grid. Classifier target size is translated as:

```text
16 m -> refinement_level 1
 8 m -> refinement_level 2
 4 m -> refinement_level 3
 2 m -> refinement_level 4
 1 m -> refinement_level 5
```

The classifier raster is polygonized in projected coordinates. Pinned rc3 refines when a refinement polygon **intersects** a candidate cell, including boundary-only contact. To prevent a polygon boundary shared with an adjacent cell from spuriously refining that neighbour, generated refinement polygons are contracted by `1e-7 m`. This is a numerical compatibility seam only; it is not a terrain/hydraulic threshold.

The actual rc3 quadtree is allowed to become finer than the classifier where sibling splitting or 2:1 topology requires it. The implementation rejects the opposite case: no source-overlapping actual face may be coarser than any validated classifier target cell it covers.

### 2. Base-grid padding and CRS

Base dimensions are `ceil(width/32)` x `ceil(height/32)`, preserving the canonical source origin. This may create quadtree padding outside odd/non-multiple-of-32 analysis dimensions.

- padding contributes no source area;
- padding faces are mapped to SFINCS mask 0;
- padding contributes zero roof-rain weight;
- source-area statistics remain based on the original Full-1 m rectangle.

HydroMT-SFINCS rc3 still requires an integer EPSG during quadtree `create()`. The implementation uses a temporary creation EPSG only, immediately replaces the topology CRS with the canonical local authority-less CRS, and restores config `epsg=None` / correct `crsgeo`.

### 3. Actual-face mask and Manning mapping

Actual rc3 face layout is read from its 1-based `level`, `n` and `m` face fields. With a 32 m base, face resolution is:

```text
32 / 2**(level - 1)
```

These exact aligned indices map each face back to its Full-1 m source block.

- no-overlap padding -> mask 0;
- any source outflow value 3 -> face mask 3;
- otherwise any active source -> face mask 1;
- active-cell Manning is averaged over the covered active source cells;
- validated road hard refinement keeps direct road cells at 1 m, so road Manning 0.020 is retained on direct road faces.

The implementation checks that every source-overlapping actual face is no coarser than the classifier target beneath it.

### 4. Area-conservative roof-rain weight aggregation

For each actual quadtree face:

```text
face_rain_weight = sum(source_1m_rain_weight) / full_face_area_m2
```

Outside-domain padding is therefore implicitly zero. The invariant is checked directly:

```text
sum(face_rain_weight * face_area_m2)
== sum(full_1m_rain_weight * 1 m2)
```

within strict deterministic floating-point tolerance.

This aggregated face weight is returned as model-building data. Adaptive spatial precipitation forcing is not yet wired in this slice.
