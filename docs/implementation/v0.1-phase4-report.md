## Confirmed blocker and disabled boundary

The pinned rc3 quadtree grid accepts a temporary integer EPSG and can be updated in memory to the canonical local AEQD on its XUGRID topology. Its writer then calls `crs.to_epsg()` and attempts to serialize the resulting `None` as the NetCDF `epsg` attribute, producing `TypeError: Invalid value for attr 'epsg': None`.

Adaptive remains rejected by the existing `GRID_ADAPTIVE_NOT_AVAILABLE` boundary. The next slice must add and validate a narrow quadtree serialization compatibility seam, real quadtree/subgrid model output, Adaptive result normalization, and the required Full-vs-Adaptive benchmark gate before enabling the mode.
