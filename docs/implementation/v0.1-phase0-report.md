## Environment and Install Commands

The repository now provides `environment.yml`. The tested isolated Windows
environment used the following equivalent commands; `<phase0-root>` was a
temporary directory outside the repository:

```powershell
python -m pip install --target <phase0-root>\site uv
<phase0-root>\site\bin\uv.exe python install 3.12.10 --install-dir <phase0-root>\python
<phase0-root>\python\cpython-3.12.10-windows-x86_64-none\python.exe -m venv <phase0-root>\venv
<phase0-root>\site\bin\uv.exe pip install --python <phase0-root>\venv\Scripts\python.exe <hydromt_sfincs-v2.0.0-rc3-checkout> netCDF4 pytest
```

The checkout was obtained from the official `Deltares/hydromt_sfincs`
`v2.0.0-rc3` tag. The harness clears a non-numeric inherited `DEBUG` value
only while importing this pre-release package; the observed shell value was
`DEBUG=release` and otherwise causes a Pydantic import error.

are metres; `msk` uses `-`; non-finite depth values are rejected and `msk`
identifies active cells.

## SFINCS Acquisition and License

The executable was supplied by the user as a local v2.4.0 Galibier Windows
release and installed for local validation. The permanent report intentionally
records no machine-specific path. No binary, generated model, or generated
result was committed or redistributed. The release directory includes the
Deltares Freeware Executable license notice; that license is non-transferable,
non-sub-licensable, limits use to the licensee's organization, and imposes
confidentiality and distribution restrictions. The HydroMT-SFINCS source is
GPL-3.0. Product redistribution/managed bootstrap remains a later-phase
license and packaging issue.

## Warnings and Unresolved Questions

  the minimal model instances; construction still succeeds.
- The plugin currently fails to import if an inherited non-numeric `DEBUG`
  value is present; the harness documents and isolates this workaround.
- Final product engine bootstrap/redistribution must be adjudicated against
  the Deltares executable license before later packaging or distribution.
