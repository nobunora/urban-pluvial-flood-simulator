`validated`

Phase 3+ functionality was not implemented.

## Implemented boundary

- `floodsim/providers/geocoder.py` uses only the approved CSIS Simple Geocoding
  endpoint, the shared network/retry policy, defensive XML parsing, WGS84
  validation, candidate ordering, and a ten-candidate cap.
- `floodsim/api/routes_geocode.py` exposes `GET /api/v1/geocode` with trimmed
  and bounded input, CSIS attribution metadata, and stable 400/503 errors.
- `floodsim/providers/jma.py` parses official AMeDAS station CSV and explicit
  official rainfall ranking labels for 10-minute, 1-hour, and daily events.
  Runtime loading validates and caches the packaged JSON catalog; it does not
  scrape JMA at application startup or API request time.
- `data/jma/stations.json` contains 1,286 precipitation-capable stations.
  `data/jma/rainfall_extremes.json` contains six deterministic events from the
  packaged official ranking sources, with `profile_available=false`.
- `floodsim/api/routes_rainfall.py` exposes nearest stations, station extremes,
  and event lookup with stable 404/503 errors.
- `scripts/build_jma_rainfall_catalog.py` provides deterministic maintenance
  generation from official source snapshots and supports focused station
  limits.
- `web/openapi.json` and `web/src/api/generated.ts` are generated by
  `openapi-typescript`; `npm run api:check` detects drift.
