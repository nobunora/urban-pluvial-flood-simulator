## Implemented boundary

- `floodsim/providers/geocoder.py` uses only the approved CSIS Simple Geocoding endpoint, shared network/retry policy, defensive XML parsing, WGS84 validation, provider ordering, and a ten-candidate cap.
- `floodsim/api/routes_geocode.py` exposes `GET /api/v1/geocode` with trimmed/bounded input, CSIS attribution metadata, and stable errors.
- `floodsim/providers/jma.py` parses official AMeDAS station data and explicit JMA rainfall ranking labels for 10-minute, 1-hour, and daily events.
- Ranking parsing is limited to ranks 1..10; the statistics-period column cannot become a false rank-11 event.
- `data/jma/stations.json` contains 1,286 precipitation-capable stations.
- `data/jma/rainfall_extremes.json` contains 60 deterministic events from the two packaged official ranking snapshots: 2 stations × 3 supported durations × 10 ranks.
- Every packaged event contains station longitude/latitude and runtime loading verifies station ID, name, and coordinates against `stations.json`.
- Nearest-station search considers all packaged precipitation-capable stations. Stations without packaged event snapshots may legitimately return an empty extremes list.
- Runtime loading validates schema version, rank bounds, event metadata type, profile consistency, and station/event identity/coordinate consistency.
- `scripts/build_jma_rainfall_catalog.py` preserves every recognized top-ten event in supplied ranking snapshots.
- The JMA maintenance generator accepts only official HTTPS `jma.go.jp` hosts for source/provenance URLs and rejects lookalike hosts, credential-bearing URLs, non-standard HTTPS ports, and non-HTTPS URLs.
- Every ranking source must expose recognized 10-minute, 1-hour, and daily rainfall rows or generation fails explicitly.
- `tests/test_phase2b_generator_contracts.py` locks the official-source and required-duration contracts.
- `RainfallEventResponse` exposes station coordinates and `event_date_or_datetime_metadata: str | null`.
- `web/openapi.json` and `web/src/api/generated.ts` are deterministic generated API contracts.
- `web/scripts/api-types.mjs --check` ignores CRLF/LF convention differences only; substantive generated-contract differences still fail.
- `.gitattributes` pins `web/index.html`, generated API artifacts, and `floodsim/static/**` to LF for Windows/POSIX build stability.
