# 4. State architecture

React `useReducer` + Contextを使用。

workflow stateを大量のtop-level `useState` flagへ分散しない。

## AppState

```ts
type AppMode = 'SETUP' | 'RESULT';

type AppState = {
  mode: AppMode;
  backend: BackendState;
  setup: SetupState;
  run: RunLifecycle;
  result: ResultState | null;
  ui: UiTransientState;
};
```

## Setup

```ts
type SetupState = {
  location: LocationSelection;
  area: AreaSelection | null;
  rainfall: RainfallSelection;
  accuracy: 'full_1m' | 'adaptive';
  estimate: ResourceEstimateState;
};
```

`canStartRun`はselectorでderived。booleanとして保存禁止。

## Run lifecycle

```ts
type RunLifecycle =
  | { kind: 'IDLE' }
  | { kind: 'SUBMITTING' }
  | { kind: 'ACTIVE'; runId: string; snapshot: RunSnapshot; lastSequence: number }
  | { kind: 'CANCELLING'; runId: string }
  | { kind: 'COMPLETE'; runId: string }
  | { kind: 'FAILED'; runId?: string; error: UiError }
  | { kind: 'CANCELLED'; runId: string };
```

`isDownloading`等の重複booleanを追加しない。

## Result

```ts
type ResultLayer = 'max_depth' | 'time_depth' | 'grid_resolution';
type DepthColorMode = 'bands' | 'rainbow';
```

time labelはmetadata.times[timeIndex]からderived。

## Action名

`LOCATION_SELECTED`、`AREA_PRESET_SELECTED`、`RUN_EVENT_RECEIVED`等domain eventを使う。`SET_DATA`、`UPDATE`、`HANDLE_CHANGE`等は禁止。

# 5. State invariant

必須test:

1. RESULTならcompleted run + metadata loaded。
2. adaptiveはbackend capabilityに従う。
3. presetはcenter必須。
4. rectangleはsearch result不要。
5. rectangle-only station searchはcentroid。
6. submissionはsummaryと同じarea/rain/accuracy object。
7. active run中setup mutation不可。
8. stale SSE sequence無視。
9. terminal eventでSSE close。
10. new analysisはsetup保持、result view clear。

---

# 6. HTTP client

1つのAPI client module。

- same-origin base;
- JSON;
- content type確認;
- backend stable error→UiError;
- AbortController;
- generic retryなし。

provider retryはbackend責務。

production consoleへraw address query/responseを出さない。

---

# 7. SSE client

`api/sse.ts`がEventSource lifecycleを所有。

- active runあたり1つ;
- old sourceを閉じてからnew;
- `sequence <= lastSequence`無視;
- transport error時はGET runで1回reconcile;
- terminalでclose;
- unmountでclose;
- componentごとにreconnect loopを作らない。

malformed event→`UI_BAD_RUN_EVENT` + reconciliation。

# 8. Map実装

MapLibre GL JS固定。

## Base map

GSI標準地図raster:

```text
https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png
```

attribution:

```text
国土地理院
```

## Coordinate order

MapLibreは `[longitude, latitude]`。

helper:

```ts
toLngLatTuple(point: LonLat): [number, number]
```

domain stateとmap code間でraw tupleを使わない。

## Center marker

1 marker instance。location stateから更新。

## Area source

1 GeoJSON source。outline + translucent fill。

map geometryはstateのrenderであり、map object自体を正本stateにしない。

# 9. 矩形drawing

rectangleだけのためにdraw framework dependencyを追加しない。

`areaDrawing.ts`で実装。

1. rectangle mode→crosshair。
2. pointer down→start lon/lat保存、map pan一時disable。
3. move→preview。
4. up→west/east/south/north normalize。
5. negligible drag reject。
6. metric width/height/area計算。
7. commit action。
8. map pan復帰。

Escapeでcancel。unmount/errorでもinteractionを必ず復帰。

screen pixelからarea計算禁止。

# 10. Component契約

## LocationStep

local search textのみcomponent local。selected canonical locationはapp state。

- Enter submit;
- blank disabled;
- new searchでold request cancel;
- keyboard candidate;
- provider attribution。

## AreaStep

state/callbackのみ。API policyを直接持たない。

## RainfallStep

custom input emptyを0にしない。canonical stateはvalid numberまたはincomplete明示。

## AccuracyStep

real radio semantics。

backend capability:

```ts
adaptive: {
  available: boolean;
  status: 'experimental' | 'recommended' | 'unavailable';
  reason?: string;
}
```

## RunSummary

pure display。submissionと別計算しない。

## RunProgress

backend snapshotをrender。SFINCS log parsing禁止。

## ResultPanel

presentation controlのみ。run config変更禁止。

# 12. Resource estimate

area + accuracy valid後**300ms debounce**。

- stale request cancel;
- latest wins;
- estimate failでもsetup自体はvalidのまま、`推定できませんでした`;
- rectangle drag中はrequestしない、commit後のみ。

ETAなし。

---

# 13. Historical rainfall flow

location/centroid変更:

1. nearest stations refresh、v0.1はnearest first選択。
2. 300ms debounce fetch。
3. station選択→extremes。
4. event選択→event ID + mode。
5. event変更時はuniformへreset。profile availableかつ再選択した場合のみobserved。

profileのないeventでprofile stateを残さない。

historical API errorでもcustom tabは使える。

---

# 14. Validation

custom rain:

```text
>0 and <=500 mm/h
integer duration 1..10080 min
```

blurまたはrun attempt後にerror。silent clamp禁止。

coordinate rangeはUI spec通り。

searchは200 code point超でlocal reject。

# 15. Submission / final review

`解析開始`は直接POSTしない。

```text
click
→ ReviewRunModal immutable snapshot
→ confirm
→ snapshotそのものをPOST /runs
```

modal open中underlying editをdisable。

POST成功→run ID→SSE→progress。

失敗→SETUP維持、config保持。

---

# 16. Progress

backend stage→Japanese mappingはexhaustive object。

TypeScript `satisfies Record<RunStage,string>`等でbackend enum追加時build failさせる。

`progress_fraction`があるときだけdeterminate。なければindeterminate。

SFINCS fake%/ETA禁止。

---

# 17. Cancel flow

1. UI CANCELLING。
2. POST cancel。
3. backend terminal event/snapshot待ち。
4. network fail→GET run reconcile。
5. cancel POST成功だけでcancelled扱いしない。

backend `CANCELLED`後:

```text
解析を中止しました。
```

SETUP編集へ戻す。RESULTへ行かない。

---

# 18. Result image overlay

backend bounds + PNG endpointをMapLibre `image` source等で配置。

URLはrun/layer/time/color/revision等でdeterministic cache key。毎render random timestamp禁止。

layer/time変更時はold imageを即blankにせずloadingを明示。stale completionはdiscard。

深度color mappingは**backendがcolorized PNG + legend metadataを出す方式を推奨/基準**。frontend独自の別depth classificationを作らない。

grid categorical paletteは固定levelならfrontend定数可。

---

# 19. Point inspect

click:

1. previous inspect abort。
2. loading。
3. backend inspect request。
4. exact value表示。
5. click marker保持。

PNGからdepth sample禁止。

`has_data=false`はno-data表示、0扱いしない。

rapid clickはlatest wins。

---

# 20. Timeline

sourceは`result.metadata.times`。

```text
min=0
max=times.length-1
step=1
```

HH:MM、24h超は`DD日 HH:MM`。

index間補間禁止。

arrowはclamp。

layer切替後time layerへ戻ったら同result内ではlast index復帰。
