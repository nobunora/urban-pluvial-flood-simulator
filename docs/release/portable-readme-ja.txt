都市内水氾濫シミュレータ v0.1.17 Windows版

このZIPだけで起動・解析できます。Python、SFINCS、GISライブラリの追加インストールは不要です。

起動方法
1. ZIP全体を任意のフォルダへ展開します。
2. UrbanPluvialFloodSimulator.exe をダブルクリックします。
3. ブラウザが開いたら「サンプル」を押し、「解析済みデータを読み込む」を選びます。
4. 一覧からサンプルを選ぶと、浸水深、標高、流速ベクトル、粒子フローを確認できます。

同梱サンプル
- 2025年 四日市: ±2000 m、1 m格子、60分、15分間隔
- 2026年 千葉: ±1000 m、1 m格子、60分、15分間隔
- 2019年 佐賀: ±500 m、1 m格子、60分、15分間隔
- 2026年 名古屋: ±500 m、1 m格子、60分、15分間隔
- 2000年 名古屋: ±500 m、1 m格子、60分、15分間隔

新規解析
画面で場所と条件を設定して「解析実行」を押します。同梱の自己ビルドSFINCSが自動的に使われます。

注意
- 結果は防災判断や避難判断に用いる公式予報ではありません。
- 下水道、浸透、河川水位、潮位・高潮、雨の空間分布、雨水ます、建物内部、陸橋・トンネル・高速道路下などの立体交差は考慮していません。
- SFINCSのライセンス、ビルド情報、対応ソースは sfincs フォルダにあります。
