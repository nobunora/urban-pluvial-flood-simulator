# 水魔法選択モック

`index.html` を開くか、このフォルダで `python -m http.server 8025 --bind 127.0.0.1` を実行し `http://127.0.0.1:8025/` を開く。

1件だけの独立したUIモック。模式地図での配置、数量・半径・時間編集、等価水深表示、GIFの再生／停止・表示切替を確認する。解析エンジンや本体UIとは未接続。地図はドラッグ移動やズームに対応せず、クリックで配置点を変更する。模式上の大きさから実地形の範囲を決めない。

並び順は推定総水量の下限、上限、固定ID。単位は一覧モデルではLに統一。ゲーム識別アイコンは独自の仮GW2バッジであり、公式ゲームアイコンではない。正式アイコンは製品実装で別途取得・確認する。アイコン48 px、テキスト24 px×2行。
