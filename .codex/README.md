# Codex Contracts

This directory contains repository-agent prompt contracts for the GitHub specification workflow.

- `repository-review.md` - read-only compatibility review before implementation.
- `implementation.md` - implementation and verification after the specification is validated.

These prompts are intentionally model-name independent. Supply the target specification path when starting a task.

See `docs/19_chat_github_codex_workflow.md` for the complete handoff flow.
