# Skill Governance

- Use the smallest available Skill that matches the request and read its complete `SKILL.md` before task actions.
- Define user goal, trigger phrases, inputs, outputs, limits, safety boundaries, and success criteria before authoring a Skill.
- Keep instructions concise, use directly linked references for detail, and validate every Skill after editing.
- Test bundled scripts safely and keep Skills free of credentials, destructive defaults, generated artifacts, and project-specific secrets.
